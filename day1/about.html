About QuickNotes

Quicknotes is a simple note-taking app designed to help you capture ideas quickly and efficiently.

How to use QuickNotes

Here's how to get the most out of QuickNotes:

  1. Open QuickNotes
  2. Create a new note
  3. View Saved Notes
  4. Edit or Delete Notes
  5. Sync across devices

Features

  • Easy to use interface
  • Quick note creation
  • Organize notes with tags
  • Search functionality
  • Cloud sync for access anywhere

Key Board Shortcuts

  1. CNTRL + O - Open QuickNotes
  2. CNTRL + N - Create a new note
  3. CNTRL + S - Save the current note
  4. CNTRL + D - Delete the current note
  5. CNTRL + F - Search notes
  6. CNTRL + SHIFT + S - Save all notes
  7. CNTRL + SHIFT + D - Delete all notes
  8. ALT + F4 - Close QuickNotes
